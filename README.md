# 🏕️ CampLife Clicker

Автоматический помощник для бронирования кемпингов на [CampLife.com](https://www.camplife.com).

**CampLife Clicker** автоматически нажимает на выбранную дату в календаре бронирования в заданное время (по умолчанию — **00:00:00**), после чего пытается нажать кнопку **Continue**.

Программа предназначена для бронирования популярных кемпингов, где свободные места открываются ровно в полночь.

---

## 💻 1. Что нужно установить

Для запуска на Mac понадобятся:

1. **Python 3** — https://www.python.org/downloads/
2. **Visual Studio Code** — https://code.visualstudio.com/
3. **Python extension для VS Code** — устанавливается непосредственно в VS Code.

После установки VS Code:

- Открой VS Code.
- Перейди в **Extensions** (Command + Shift + X).
- Найди расширение **Python** от Microsoft.
- Нажми **Install**.

## 📂 2. Подготовка программы

Вместе с инструкцией ты получишь два файла:

- `main.py` — исходный код программы.
- `requirements.txt` — список необходимых Python-библиотек.

Создай папку `CampLifeClicker` и сохрани туда оба файла.

В VS Code выбери **File → Open Folder** и открой папку `CampLifeClicker`.

## ⚙️ 3. Установка библиотек и Chromium

В VS Code открой встроенный терминал:

**Terminal → New Terminal**

Выполни следующие команды по очереди:

**Установка библиотек:**

```bash
python3 -m pip install -r requirements.txt
```

**Установка Chromium для Playwright:**

```bash
python3 -m playwright install chromium
```

Chromium устанавливается автоматически. Дополнительно устанавливать Google Chrome или расширения для него не требуется.

Все необходимые зависимости установлены.

## 🍎 4. Разрешения macOS

Программа использует PyAutoGUI для автоматического управления мышью.

1. Открой **System Settings → Privacy & Security → Accessibility**.
2. Нажми `+` и добавь **Visual Studio Code**.
3. Включи разрешение на управление компьютером.

Если запускаешь программу из обычного Terminal, предоставь разрешение и ему.

При необходимости перезапусти VS Code.

## 🚀 5. Запуск программы

1. Открой файл `main.py` в VS Code.
2. При необходимости выбери установленный Python 3 через **Python: Select Interpreter**.
3. Нажми **Run Python File** (кнопка ▶ в правом верхнем углу).

Альтернативно можно запустить программу через терминал VS Code:

```bash
python3 main.py
```

После запуска откроется отдельное окно Chromium со страницей CampLife.

В терминале появится сообщение о времени запланированного клика.

**Важно:** не закрывай VS Code и не останавливай программу до завершения бронирования.

## 🏕️ 6. Как пользоваться программой

### Шаг 1. Запусти программу

Запусти `main.py` за несколько минут до полуночи.

Откроется браузер Chromium со страницей бронирования CampLife.

### Шаг 2. Авторизуйся

Войди в свой аккаунт CampLife вручную, введя логин и пароль.

### Шаг 3. Выбери кемпинг

Перейди на страницу нужного кемпграунда и выбери конкретное место (site), которое хочешь забронировать.

### Шаг 4. Заполни информацию

В форме бронирования укажи:

- **Adults:** 2 человека (или нужное количество).
- **Equipment:** Tent (палатка).
- **Equipment Length:** 20 feet (или фактический размер).

Проверь остальные параметры бронирования.

### Шаг 5. Выбери дату заезда

В календаре выбери дату начала кемпинга (Check-in).

**Не нажимай на дату выезда (Check-out)!**

Это действие программа должна выполнить автоматически в полночь.

### Шаг 6. Наведи курсор на дату выезда

Перемести указатель мыши точно на нужную дату выезда в календаре.

После этого:

- Не двигай мышь.
- Не переключай окна.
- Не меняй масштаб браузера.
- Не закрывай Chromium.
- Не позволяй Mac перейти в спящий режим.

Программа выполнит клик именно в той точке экрана, где находится курсор.

### Шаг 7. Автоматическое бронирование

В заданное время (по умолчанию — 00:00:00) программа:

1. Выполнит первый клик мышью на дате выезда.
2. Подождёт 2 секунды.
3. Найдёт кнопку **Continue**.
4. Попытается автоматически нажать Continue.
5. Оставит браузер открытым на 10 минут.

### Шаг 8. Заверши бронирование

После автоматических кликов проверь, что сайт перешёл на следующий этап.

При необходимости самостоятельно введи платёжные данные и подтверди бронирование.

**Программа не оплачивает бронирование автоматически и не гарантирует получение места.**

---

## ⏰ 7. Рекомендации перед бронированием

**Когда запускать?**

Рекомендуется открыть программу и подготовить страницу за 2–3 минуты до полуночи.

Слишком ранняя подготовка может быть неэффективной, если сайт обновит страницу или сбросит выбранные параметры.

**Что проверить?**

- Компьютер подключён к интернету.
- Mac не перейдёт в спящий режим.
- Время и часовой пояс компьютера установлены правильно.
- Нужная дата заезда уже выбрана.
- Курсор находится точно на дате выезда.
- Окно Chromium открыто поверх других окон.

**Важно:** первый клик выполняется по текущему положению мыши. Если курсор сместится, программа нажмёт не туда.

## ⚙️ 8. Настройки программы

Настройки находятся в начале файла `main.py`:

```python
URL = "https://www.camplife.com/1010/reservation/step1"
TIMEZONE = "America/Los_Angeles"
TARGET_TIME = "00:00:00"
HEADLESS = False
BUTTON_TEXT = "Continue"
```

| Параметр | Назначение |
|---|---|
| `URL` | Адрес страницы бронирования |
| `TIMEZONE` | Часовой пояс для автоматического клика |
| `TARGET_TIME` | Время клика в формате ЧЧ:ММ:СС |
| `HEADLESS` | `False` — показывать браузер |
| `BUTTON_TEXT` | Текст кнопки для второго клика |

По умолчанию программа ждёт ближайшую следующую полночь по времени Los Angeles.

Чтобы изменить время, например для тестирования, укажи:

```python
TARGET_TIME = "18:30:00"
```

После изменения настроек сохрани файл и перезапусти программу.

## 🧪 9. Тестирование

Перед настоящим бронированием рекомендуется проверить работу программы.

1. Измени `TARGET_TIME` на время через 3–5 минут.
2. Запусти программу.
3. Открой тестовую страницу или этап, на котором можно безопасно проверить первый клик.
4. Наведи курсор на нужную кнопку.
5. Проверь, сработал ли клик.

После проверки верни значение:

```python
TARGET_TIME = "00:00:00"
```

## ❗ 10. Возможные ошибки

**ModuleNotFoundError**

Не установлены необходимые библиотеки или выбран другой Python.

Повтори:

```bash
python3 -m pip install -r requirements.txt
```

**Ошибка запуска Chromium**

Выполни:

```bash
python3 -m playwright install chromium
```

**Мышь не нажимает автоматически**

Проверь разрешение Accessibility для VS Code в настройках macOS.

**Не нажимается Continue**

Возможно, кнопка не появилась вовремя, сайт изменил интерфейс или открыл новое окно. Проверь сообщение об ошибке в терминале.

**Как остановить программу?**

Нажми кнопку остановки в VS Code или `Control + C` в терминале.

---

## 📌 Как работает программа

CampLife Clicker использует:

- **Python** — основной язык программы.
- **Playwright** — открытие браузера и поиск кнопки Continue.
- **PyAutoGUI** — физический клик мышью по текущей позиции курсора.
- **pytz** — определение времени с учётом заданного часового пояса.

После запуска программа ожидает указанного времени, выполняет последовательность кликов и оставляет браузер открытым для ручного завершения бронирования.

**Главное условие успешной работы — правильно подготовленная страница и неподвижный курсор мыши в момент первого клика.**
